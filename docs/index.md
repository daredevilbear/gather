# Gather

A self-hosted dashboard for services, accounts, personal dashboards,
notifications, and visual configuration, based on Homepage.

**[Open the Gather documentation](gather/index.md)**

- [Set up Gather](gather/setup.md)
- [Edit your dashboard](gather/settings.md)
- [Manage accounts and personal dashboards](gather/administration.md)
- [Configure notifications](gather/notifications.md)
- [Operate, upgrade, and back up](gather/operations.md)
- [Troubleshoot](gather/troubleshooting.md)
- [Browse service integrations](widgets/services/index.md)

The Gather guides describe this fork. The inherited configuration and widget
references remain available for Homepage-compatible features. Use documentation
from the branch or commit matching your installation; `dev` follows development
and `main` follows releases.
